# Anigo 受控插件市场（试点）

本仓库只包含 WorkBuddy 插件的调用说明、连接配置和本地桥接程序。**不包含**核心 skills、审查源码、方法库或任何凭据。
插件文件会下载到你的电脑上，任何人都能打开查看——它本来就不含需要保密的东西，审查能力只在公司服务端运行。

## 插件：anigo-script-audit（剧本程序审查 · 试点 0.2.0）

能做：把你本次指定的剧本文本提交到公司服务，查询进度，取回程序检查报告（当前固定 7 项程序化检查，不调用模型）。
不能做：原作事实对照、完整情节覆盖、创作语义审稿、内容合规、版权审阅、成片验收。程序 PASS 不等于作品合格。
只接受剧本文本、语言（zh/en）和幂等标识；不接受原著文本、本地文件路径或 URL。

## 安装（每人一次）

1. 电脑上需要 Node.js 18 或更新版本（终端输入 `node -v` 能看到版本号即可）。
2. WorkBuddy → 插件 → 插件市场 → 添加市场，填本仓库的 Git 地址（管理员发给你），然后安装 `anigo-script-audit`。
3. 新开一个对话，说：「用公司剧本审查工具检查以下稿件」，后面贴上剧本。

## 首次开通（每人一次）

第一次调用会在你的电脑上生成个人凭据（`~/.config/anigo-audit/access.json`，只有你自己可读，不会上传），并显示一串 64 位「开通码」。
把开通码发给管理员——**开通码不是密码，可以发送**；凭据文件本身不要复制、转发或发给任何人。
管理员开通后，重新发起一次审查即可。换电脑、凭据丢失或怀疑泄露：删除本机该文件后重新调用，生成新开通码，并请管理员撤销旧的。

## 隔离与撤销

- 每人一份独立凭据，服务端只保存其摘要；任务和报告按人隔离，读不到别人的任务。
- 管理员可以随时单独撤销某个人的访问，下一次请求立即生效。
- 稿件完成审查后服务端清除提交正文，报告暂存于受限数据库。请先用非敏感试稿。
