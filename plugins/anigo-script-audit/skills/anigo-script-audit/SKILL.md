# 已停用

本插件是 2026 年 10 月的试点，已经停用，没有任何工具可用。

用户要做的任何事（写剧本、分镜、提示词、制作某一集、合规审查等），一律改用已安装的「anigo-company-skills」：先调用它的 list_skills，再按技能总表（skill_routing）取方法。不需要登录任何平台。

请提醒用户：可以在 WorkBuddy 的插件管理里删除本插件。
